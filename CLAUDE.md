# MMR Passport Renewal Monitoring System

Before doing any work in this repo, read:

- `memory.md` — architecture, key decisions and why, data-format quirks,
  debugging history. Read this first.
- `README.md` — setup steps, env vars, deploy process (Render/Vercel/GitHub
  Actions/Neon), admin Passkey enrollment.
- `userGuide.md` — the end-user-facing flow (what the public signup form
  promises, what the Terms & Conditions say), for context on any
  user-facing change.

This is a public community tool, not a personal project — changes to the
public signup flow, data handling, or Terms & Conditions should be
consistent with what `userGuide.md` already promises users.
